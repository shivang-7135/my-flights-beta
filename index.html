Live flight status

1 · Get a free key (opens rapidapi.com)

Delays, new times and gates come from the AeroDataBox service, which needs a free personal key. Step 1 opens its page: create an account there, choose the free "Basic" plan, and copy the value shown as "X-RapidAPI-Key". Come back and tap step 2. The key has to be created by you once; the app cannot do that part for you. When status is checked, the app sends only the flight number and date — never names, booking references or pictures. The key is kept on this phone. An iPhone web app cannot check while it is closed.

Reading tickets

Looks up which airports a flight number normally connects (service: adsbdb.com, no key) and warns when a ticket was read differently. Sends only the flight number.

Backup

The backup holds all tickets and pictures in one file that you keep yourself (Files, AirDrop, a USB stick). Use it before changing phones.
